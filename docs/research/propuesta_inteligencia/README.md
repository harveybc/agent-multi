La propuesta estudia si una calibración de capacidad, el exceso de ajuste específico
y la mejora fuera de muestra permiten estimar tempranamente el menor tamaño que
alcanza una meta de desempeño. El tamaño suficiente depende explícitamente de esa
meta y se observa dentro de un conjunto de modelos fijado. La fase temporal emplea
señales con componentes limpios y ruido conocidos; SynTSBench y `dysts` son
antecedentes o comprobaciones externas, no contribuciones reclamadas.

Las diferencias de pérdida pueden expresarse en base dos, pero la unidad no forma
parte del título ni convierte las variables en porciones de una memoria común. La
propuesta no usa `U*/C` como ocupación ni una longitud comprimida como cota inferior
del número de parámetros.

Convención editorial: **pronóstico** se reserva para valores futuros de una serie
temporal; **predicción** conserva su uso general en clasificación, teoría del
aprendizaje e información predictiva. No se hacen reemplazos mecánicos entre ambos.

Los documentos históricos conservan el nombre anterior cuando identifican la versión
que evaluaron. La propuesta vigente usa un nombre coherente con su pregunta científica.
