## Verification Pass AT-ACADEMIC-031

- Sources: official publisher or project pages, author-hosted manuscripts,
  arXiv/IACR records and Crossref bibliographic metadata.
- Exact title queries were combined with first-author surname and DOI where
  available. Topic queries were limited to resolving the eight seeded rows:
  `BOINC public-resource computing`, `blockchained on-device federated
  learning`, `proof of learning definitions practice`, `practical Byzantine
  fault tolerance`, `Bitcoin whitepaper`, `parallelism evolutionary
  algorithms`, `proofs of useful work`, and `Kademlia XOR metric`.
- Inclusion: the seeded work or its authoritative replacement; primary text
  opened; metadata and supporting section identified.
- Exclusion: secondary summaries as evidence; unverifiable metadata;
  superseded versions whose correction changes the claim boundary.
- Duplicates: DOI first, then canonical title plus year.
- Correction check: publisher or repository notices plus Crossref relation
  metadata where available. The 2017/203 Proofs of Useful Work seed was
  rejected because its primary manuscript redirects readers to 2018/559.

This pass verifies sources. It does not establish novelty. A systematic search
must add databases, full query strings, inclusion counts, excluded-source
reasons and a collision decision before any novelty language is authorized.
